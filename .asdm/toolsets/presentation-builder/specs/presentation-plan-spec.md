# Presentation Plan Output Specification

**Spec ID**: presentation-plan-spec
**Version**: 0.0.1
**Last Updated**: 2026-05-05

---

## Purpose

This specification defines the exact output format for presentation plan files generated by the `/asdm-presentation-planning` action. All generated plans must conform to this template exactly.

## File Location & Naming

- **Directory**: `.asdm/workspace/presentations/PRES-XXX/`
- **Filename**: `presentation-plan.md`
- **ID Format**: `PRES-NNN` (zero-padded 3 digits, e.g., PRES-001, PRES-012)
- **Encoding**: UTF-8

## Field Definitions

### Presentation Info Fields

| Field | Required | Type | Description |
|-------|----------|------|-------------|
| Presentation ID | ✅ | string | Unique identifier `PRES-NNN` |
| Created Date | ✅ | date | ISO 8601 date |
| Updated Date | ✅ | date | ISO 8601 date |
| Status | ✅ | enum | `PLANNED` or `CREATED` |
| Language | ✅ | enum | `zh-CN` or `en-US` |
| Purpose | ✅ | string | One-line description of presentation goal |
| Audience | ✅ | string | Target audience description |
| Estimated Duration | ✅ | number | Duration in minutes (5-60) |
| Total Slides | ✅ | number | Exact count of slides |
| Theme | ✅ | string | Theme name from theme-style-spec |
| Primary Color | ✅ | hex | Main color (#RRGGBB) |
| Secondary Color | ✅ | hex | Secondary color (#RRGGBB) |
| Accent Color | ✅ | hex | Accent/highlight color (#RRGGBB) |
| Source Type | ✅ | enum | `topic` / `outline` / `document` / `feature` |

### Slide Fields

| Field | Required | Type | Description |
|-------|----------|------|-------------|
| Title | ✅ | string | Slide title (1-2 lines) |
| Type | ✅ | enum | Valid slide type from slide-type-spec |
| Layout | ✅ | string | Brief layout description |
| Content | ✅ | list | Bullet points (1-7 items) |
| Speaker Notes | ✅ | string | Detailed notes for presenter |
| Visual Suggestion | ⬜ | string | Description of recommended visual |

## Status Transitions

```
PLANNED ──→ CREATED ──→ UPDATED
   │            │
   └────────────┘
  (re-planning)
```

- **PLANNED**: Initial state after `/asdm-presentation-planning`
- **CREATED**: After `/asdm-presentation-create` generates the .pptx file
- **UPDATED**: After re-planning or modifying an existing plan

## Validation Rules

The action must validate the generated plan against these rules:

| Rule | Severity | Description |
|------|----------|-------------|
| V001 | ERROR | Presentation ID must be unique and follow `PRES-NNN` format |
| V002 | ERROR | First slide must be type `title` |
| V003 | ERROR | Last slide must be type `thank-you` |
| V004 | ERROR | Total slide count must match actual slide entries |
| V005 | ERROR | All slide types must be valid per slide-type-spec |
| V006 | WARNING | No slide should have more than 7 bullet points |
| V007 | WARNING | Speaker notes should cover ≥80% of slides |
| V008 | WARNING | Should include at least one `summary` slide |
| V009 | INFO | Consider adding `section` dividers for presentations > 12 slides |
| V010 | INFO | Avoid more than 2 consecutive `content` slides without visual variety |

## Integration with Index

After creating a plan, the presentations index (`.asdm/workspace/presentations/index.md`) must be updated with:
- Presentation ID
- Presentation Name (title)
- Status: `PLANNED`
- Plan File: relative path to `presentation-plan.md`
- Output File: `-` (empty until created)
- Created/Updated dates
