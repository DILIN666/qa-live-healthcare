## 1. 系统概述

### 1.1 项目简介

**在线医疗咨询平台**是一个连接患者与专业医生的 Web 问诊系统，提供便捷、高效的在线医疗咨询服务。患者可通过平台浏览医生信息、向医生提交健康咨询问题；医生可登录个人诊室查看并回复患者问题。

### 1.2 核心业务流程

```
┌─────────────┐     ┌─────────────┐     ┌─────────────┐
│   患者端    │────▶│   平台核心   │────▶│   医生端    │
└─────────────┘     └─────────────┘     └─────────────┘
      │                   │                   │
      │ 1. 浏览医生        │ 3. 问题路由       │ 4. 回复问题
      │ 2. 提交咨询        │                   │
      │                   │                   │
      └───────────────────┴───────────────────┘
                    5. 查看回复
```

│                                                                  │

│  └───────────────────────────────────────────────────────────┘  │
│                                                                  │
└─────────────────────────────────────────────────────────────────┘

### 5.2 路由守卫设计

| 路由 | 守卫 | 说明 |
|------|------|------|
| `/doctor/room/:username` | 需登录 | 检查医生登录状态 |
| `/consultation/:username` | 可选登录 | 患者可匿名提交 |

### 5.3 路由参数设计

| 参数 | 类型 | 来源 | 说明 |
|------|------|------|------|
| `doctorUsername` | URL Params | 患者选择医生 | 指定咨询的医生 |
| `username` | URL Params | 医生登录 | 医生诊室标识 |

## 10. 设计决策记录

### 10.1 关键设计决策

| 决策项 | 选择 | 原因 |
|--------|------|------|
| **前端框架** | Vue 3 | 渐进式、易上手、生态完善 |
| **状态管理** | Vue Reactive | MVP 阶段简单够用 |
| **UI 框架** | Ant Design Vue | 企业级组件、风格统一 |
| **构建工具** | Vite | 极速开发体验、HMR 快 |
| **路由管理** | Vue Router | Vue 官方推荐 |
| **数据存储** | 静态 JSON | MVP 快速验证 |

### 10.2 技术选型理由

| 技术 | 替代方案 | 选择理由 |
|------|----------|----------|
| Vue 3 | React | Vue 中文文档友好、学习曲线平缓 |
| TypeScript | JavaScript | 类型安全、IDE 支持好 |
| Vite | Webpack | 启动快、HMR 即时、开发体验佳 |
| Ant Design Vue | Element Plus | 企业级风格、组件丰富 |
